# Customization

The Agent Overview component supports customization through theming, translations, and callbacks.

## Styling

By default, importing React components from this library does not pull any CSS into your project.

To use the starter styles, add the following import:

```js
import '@constructor-io/constructorio-ui-agent-overview/styles.css';
```

- All starter styles are scoped within the `.cio-agent-overview-root` CSS selector.
- These styles are intended to be extended by layering in your own CSS rules.
- To opt out completely, simply do not import the stylesheet.

> When using the JavaScript Bundle, CSS is included by default via the `includeCSS` option (defaults to `true`).

## Theming

The `theme` prop provides fine-grained control over the component's visual appearance via CSS custom properties. All theme values are sanitized before being applied.

```jsx
<CioAgentOverview
  apiKey="YOUR_API_KEY"
  intent="I want to buy shoes"
  domains={{ suggestions: 'searchbar', results: 'explorer' }}
  theme={{
    fontFamily: 'Inter, sans-serif',
    primaryColor: '#1a1a1a',
    secondaryColor: '#4a4a4a',
    borderColor: '#e0e0e0',
    background: '#ffffff',
    spacingMd: '16px',
  }}
/>
```

## Translations

All UI strings can be customized via the `translations` prop for internationalization:

```jsx
<CioAgentOverview
  apiKey="YOUR_API_KEY"
  intent="I want to buy shoes"
  domains={{ suggestions: 'searchbar', results: 'explorer' }}
  translations={{
    'CioAgentOverview.section.aiBadge': 'IA',
    'CioAgentOverview.categories.viewSuggestions': 'Ver sugerencias',
    'CioAgentOverview.section.viewMore': 'Ver todo',
    'CioAgentOverview.skeleton.thinking': 'Cargando...',
    'CioAgentOverview.error.message': 'Algo salió mal',
  }}
/>
```

## Callbacks

The `callbacks` prop lets you handle user interactions:

```jsx
<CioAgentOverview
  apiKey="YOUR_API_KEY"
  intent="I want to buy shoes"
  domains={{ suggestions: 'searchbar', results: 'explorer' }}
  callbacks={{
    onProductClick: (event, product, section) => {
      console.log('Product clicked:', product.itemName);
    },
    onCategoryClick: (category) => {
      console.log('Category selected:', category.title);
    },
    getProductUrl: (product) => `/products/${encodeURIComponent(product.url)}`,
    getViewMoreUrl: (section) => `/search?q=${encodeURIComponent(section.title)}`,
  }}
/>
```
